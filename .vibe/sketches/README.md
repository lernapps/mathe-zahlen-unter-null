# Skizzen

- `zahlengerade.svg`: Zahlengerade der Musterseite. Gleiche Abschnitte, Hauptstriche beschriftet, Null fett, links negativ; Beschriftung „negative/positive Zahlen“ trägt die Information, nicht Farbe. Textalternative im `desc`.
- Musterseite `negative-zahlen`, Ablauf: 1. Chat (2-3 Nachrichten Messstation) → 2. Aufgabe „Thermometer ablesen“ (Auswahl, Rückmeldung mit Grund) → 3. Zahlenstrahl bekommt linkes Ende, Bild + Text „ab jetzt Zahlengerade“ → 4. Beispielkasten −3 °C → 5. Merke (Minus ist Vorzeichen, links der Null) → 6. Übung: ≥4 Aufgaben (ablesen, einordnen, Kontostand, Meeresspiegel; je mit Fehlerdiagnose).
- Pfeile für Addieren/Subtrahieren: gleiche Gerade, Pfeil nach rechts (+) bzw. links (−), gleiche Länge je Betrag; Startpunkt und Ergebnis beschriftet.
